# 羊羊挂机（Sheep Idle Game）

一款竖屏 9:16、极简像素 2D 风格的轻度挂机养成小游戏。

## 当前状态

- 阶段：V0.1 需求已定稿，准备创建 Cocos 工程
- 技术方案：Cocos Creator 3.8.8 + TypeScript
- 首发目标：微信小游戏
- 后续适配：抖音小游戏
- 开发目录：`E:\GameProjects\sheep-idle-game`
- 当前仓库尚未生成 Cocos 工程

## V0.1 核心循环

给小羊喂草 → 获得挂机时间 → 自动战斗 → 获得金币和经验 → 提升等级与战力 → 推进关卡并获得宝箱 → 用金币开启宝箱获得草 → 继续挂机。

## V0.1 功能范围

1. 竖屏静态主界面
2. 喂草与挂机倒计时
3. 自动战斗与关卡推进
4. 金币、经验、等级和战力
5. 简化宝箱：消耗金币获得草
6. 本地存档与测试用重置存档
7. 离线收益结算

底部保留商城、主页、副本、背包四个入口；未开发页面仅显示“功能开发中”。

## 开发原则

- 每次只完成一个模块并单独验收。
- 所有数值配置化。
- 先保证能运行、能玩、能保存。
- 未经说明不增加第三方依赖或复杂系统。
- 发生错误时优先最小修改，不大面积重写。
