# 羊羊挂机（Sheep Idle Game）

一款竖屏 9:16、极简像素 2D 风格的轻度挂机养成小游戏。

## 当前状态

- 阶段：V0.1 项目初始化
- 技术方案：Cocos Creator 3.8 LTS + TypeScript
- 首发目标：微信小游戏
- 后续适配：抖音小游戏
- 当前仓库尚未生成 Cocos 工程；必须先通过 Cocos Dashboard 的空项目模板创建，避免手写无效工程文件。

## V0.1 核心循环

领取草和奖励 → 填满食槽 → 挂机获得金币和经验 → 提升等级 → 自动推塔 → 获得草和金币 → 继续成长。

## V0.1 功能范围

1. 竖屏主界面
2. 小羊与食槽
3. 草的获得、添加和消耗
4. 金币、经验和等级
5. 简化自动推塔
6. 每 10 层一个 Boss
7. 本地存档
8. 离线收益
9. 开发测试用重置存档

## V0.1 暂不开发

装备、完整背包、宝箱、商城、副本、交易、竞技、排行榜、皮肤、广告、充值、社交、技能、转职、云存档和正式美术。

## 开发原则

- 每次只完成一个模块并单独验收。
- 所有数值配置化。
- 先保证能运行、能玩、能保存。
- 未经说明不增加第三方依赖或复杂系统。
- 发生错误时优先最小修改，不大面积重写。
